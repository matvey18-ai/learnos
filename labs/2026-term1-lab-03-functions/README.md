# Лабораторная работа №3 — Функции в Python и базовые алгоритмы

**Папка:** `2026-term1-lab-03-functions/` · **Курс:** ВВИТ, 2026 · **Дата:** 2026-10-02

## Задание

Методичка курса, ЛР №3 (PDF стр. 39–53): функции (параметры, `return`, области видимости), списки, срезы, кортежи, встроенные функции, собственные алгоритмы (сумма, минимум/максимум, линейный поиск), `lambda`. 12 заданий, включая самостоятельное (анализ измерений из шести функций без `sum/min/max`).

Карточка источника в wiki: [[vvit-python-labs-methodical-guide-2026]] (сам PDF в репозиторий не добавлен — course-private).

## Структура

| Файл | Назначение |
| --- | --- |
| `task01.py` … `task12.py` | код по 12 заданиям методички |
| `output/taskNN.txt` | реальные выводы программ (запуск в PowerShell, включая ошибку `NameError` в задании 3) |
| `screenshots/taskNN.png` | «скриншоты» терминала: `Get-Content` с кодом + запуск + вывод |
| `tools/render_screenshots.py` | рендер скриншотов из реальных выводов (прозрачность: изображения собираются из `output/`, не рисуются руками) |
| `report.md` | отчёт с разбором каждого задания и выводами |

## Запуск

```powershell
py task01.py            # по аналогии для task02 … task12
py task12.py            # задание 12 спросит значение для поиска
py tools\render_screenshots.py   # перегенерировать скриншоты после правок
```

Среда: Windows / PowerShell, Python 3.14.4.
