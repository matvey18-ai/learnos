# ЛР №3 — Функции в Python и базовые алгоритмы

> Черновик-конспект подготовлен LLM (2026-10-02) по методичке, PDF стр. 39–53. Сверь с оригиналом; задания 8–12 выполняй без подсказок LLM — именно на них проверяется понимание алгоритмов.

## Цель

Научиться разбать программу на функции (параметры, `return`, области видимости), работать со списками, кортежами и срезами, пользоваться встроенными функциями и самому реализовывать простейшие алгоритмы (сумма, минимум/максимум, линейный поиск), включая `lambda`.

## Теория — ключевое своими словами

- **Функция** — именованный блок кода под задачу; `def имя(параметры):` + отступ. Определение **не выполняет** тело — нужен вызов `имя()`.
- **Параметр vs аргумент:** параметр — имя в определении (`def greet(name)`), аргумент — значение при вызове (`greet("Иван")`); по умолчанию связь позиционная.
- **`return` vs `print`:** `return` передаёт результат вызывающему коду (можно сохранить, использовать в выражении) и **завершает функцию** — код после него не выполняется; без `return` функция вернёт `None`. `print` лишь печатает.
- **Удобство вызова:** значения по умолчанию (`unit="см"`) и именованные аргументы (`greet(message=..., name=...)`) — можно менять порядок.
- **Область видимости:** переменная внутри функции локальна; глобальная и одноимённая локальная — независимы (выведет 20, потом 10). `global` позволяет менять глобальную, но злоупотреблять нельзя: данные — через параметры, результат — через `return`.
- **Список** (`list`) — изменяемый: индексация с 0, отрицательные (`-1` — последний), замена `numbers[1] = 100`, `append()`, `remove()`, `pop()`, `len()`. Перебор: `for x in numbers`, либо `range(len(numbers))`, если нужен индекс.
- **Срез** `seq[start:stop:step]` — `stop` **не включается**; `numbers[:]` — поверхностная копия.
- **Кортеж** (`tuple`) — неизменяемый; изменение — ошибка. Один элемент: `(10,)` — запятая обязательна. **Распаковка** `x, y = point`; `return a, b` — возврат нескольких значений = кортеж. Конвертация: `tuple(list)` / `list(tuple)`.
- **Встроенные:** `len/min/max/sum`; `sorted()` возвращает **новый** отсортированный список, `list.sort()` **меняет** список на месте; `enumerate()` даёт пары «индекс, значение».
- **Функции высшего порядка:** функция — объект, можно присвоить переменной; поэтому `sorted(numbers, key=lambda x: abs(x))` работает. `lambda параметры: выражение` — анонимная в одну строку, удобна как короткий `key`, но не заменяет обычные функции.

## Практическая часть (12 заданий, кратко)

1. `greet(name)`, `square(number)`, `max_of_two(a, b)` **без** встроенного `max()`; каждую вызвать ≥2 раза.
2. `calculate_rectangle`, `calculate_perimeter`, `describe_rectangle(width, height, unit="см")` — вызвать с аргументом `unit` и без.
3. Программа с `value = 10` / `value = 20` внутри функции: записать вывод, объяснить два значения; добавить локальную переменную и попробовать обратиться к ней снаружи.
4. Список ≥10 чисел: первый/третий/последний, изменить второй, `append`, `remove`/`pop`, вывести итог и `len`.
5. Срезы из `[1..10]`: первые три, последние три, 3-й по 7-й, каждый второй, обратный порядок.
6. Кортеж `measurements` ≥8 значений: срезы, попытка изменения (зафиксировать ошибку и объяснить), распаковка двух значений, `tuple → list → правка → tuple`.
7. Для списка: количество, сумма, min, max, среднее; `sorted()` и затем `sort()` — объяснить разницу.
8. Свои `calculate_sum`, `find_min`, `find_max` **без** `sum/min/max`, сверить с встроенными.
9. Линейный поиск `find_element(numbers, target)` → индекс первого вхождения или `-1`; проверить на найденном и отсутствующем.
10. `analyze(numbers)` → кортеж `(мин, макс, среднее)`, распаковать в три переменные.
11. `[-10, 3, -2, 8, -5]`: обычная сортировка и сортировка по модулю через `key=lambda` — сравнить и объяснить назначение lambda.
12. **Самостоятельно:** анализ измерений (список ≥10) — функции `calculate_average`, `find_minimum`, `find_maximum`, `count_above_average`, `find_value`, `analyze_measurements` (возвращает кортеж, распаковать); в первых трёх **запрещены** встроенные `sum/min/max`; вывести: количество, мин, макс, среднее, сколько выше среднего, результат поиска введённого значения.

## Требование к результату

Создавать/вызывать функции; различать параметры и аргументы; объяснять `return` vs `print`; пользоваться значениями по умолчанию и именованными аргументами; знать локальные/глобальные области видимости; работать со списками и кортежами, индексацией, отрицательными индексами и срезами; распаковывать кортежи и возвращать несколько значений; знать `len, min, max, sum, sorted, abs, round, enumerate`; реализовывать суммирование, минимум/максимум, подсчёт и линейный поиск; применять `lambda` в простых задачах.
