## Why this source matters

Полный план курса из восьми лабораторных: от Git и баз Python до ООП, PyQt6, тестирования и Linux. Первые три работы задают фундамент (контроль версий, синтаксис, функции/алгоритмы), на которых строится остальное.

## Reliable extract

_Своими словами; указатель — номер лабораторной и страницы PDF._ Аннотация, не копия текста.

- **ЛР №1 «Введение в систему контроля версий Git» (PDF стр. 4–17):** назначение VCS, отличие Git от GitHub, три зоны (рабочий каталог → индекс → история), коммиты и история, ветки и merge, конфликты, отмены через restore/revert. Практика — 10 заданий на каталоге `git_lab` с файлом `notes.txt`.
- **ЛР №2 «Введение в язык программирования Python» (PDF стр. 18–38):** интерпретатор vs компилятор (байт-код CPython), установка Python и VS Code, переменные, типы int/float/str/bool, input/print и преобразование типов, арифметика и сравнения, if/elif/else, логические операторы, циклы for/while, стандартная библиотека на примере math. Практика — 14 заданий, итоговое самостоятельное (сумма и среднее измерений).
- **ЛР №3 «Функции в Python и базовые алгоритмы» (PDF стр. 39–53):** def, параметры/аргументы, return vs print, значения по умолчанию, области видимости, списки, срезы, кортежи и распаковка, встроенные функции (len/min/max/sum/sorted/enumerate), собственные алгоритмы суммирования/поиска/линейного поиска, lambda и функция как объект. Практика — 12 заданий, итоговое — анализ измерений из шести функций без sum/min/max.
- **ЛР №4–8 (по оглавлению):** №4 организация Python-проекта (с. 54), №5 ООП, №6 GUI на PyQt6, №7 качество и надёжность кода (стиль, тесты), №8 основы операционных систем Linux.
