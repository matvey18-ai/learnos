# ЛР №2 — Введение в язык программирования Python

> Черновик-конспект подготовлен LLM (2026-10-02) по методичке, PDF стр. 18–38. Сверь с оригиналом, перепиши своими словами, прогони каждый пример руками перед сдачей.

## Цель

Настроить окружение (Python + VS Code), освоить базовый синтаксис: переменные, типы, ввод-вывод, арифметику, условия и циклы, познакомиться со стандартной библиотекой.

## Теория — ключевое своими словами

- **Как выполняется код:** исходник `.py` выполняет интерпретатор. В CPython процесс: `.py` → байт-код → виртуальная машина, поэтому деление «компилируемые vs интерпретируемые» — упрощение (компилятор C/C++ сразу даёт исполняемый файл).
- **Окружение:** Python с python.org (в Windows включить PATH), проверка `python --version` или `py --version`. VS Code — редактор, он интерпретатор **не заменяет**: нужно расширение Python от Microsoft и `Python: Select Interpreter`.
- **Синтаксис:** одна инструкция — одна строка; регистр важен (`name`/`Name`/`NAME` — разные); комментарий — `#`.
- **Переменная** создаётся в момент присваивания; имена — понятные (`student_age`).
- **Типы:** `int` (18, -5), `float` (1.82 — дробь через **точку**), `str` ("Иван"), `bool` (`True`/`False` — с заглавной). Тип узнётся через `type()`.
- **Ввод-вывод:** `print()` печатает (несколько значений через запятую); `input()` **всегда возвращает строку**, даже если ввели число → нужны `int()` / `float()`; обратно — `str()`.
- **Арифметика:** `+ - * / // % **` (`//` — целочисленное, `%` — остаток, `**` — степень); приоритет как в математике, скобки `(...)` меняют порядок. Сравнения `== != > < >= <=` возвращают `bool`.
- **Условия:** `if условие:` + отступ; `if-else`; `if-elif-else` — проверка сверху вниз до первого истинного. Логика: `and` (оба истинны), `or` (хотя бы одно), `not` (инверсия). Сравнивать bool с `True` обычно не нужно — достаточно самой переменной.
- **Циклы:** `for` — перебор/повтор заданное число раз, обычно с `range(stop)` (0…stop−1), `range(start, stop, step)`. `while` — пока условие истинно; **обязательно менять переменную условия**, иначе бесконечный цикл. Отступы — часть синтаксиса, 4 пробела.
- **Накопление:** `total = 0; total = total + i` в цикле.
- **Стандартная библиотека:** идёт вместе с Python, подключается через `import` (пример — `math.pi`, `math.sqrt(25)`).

## Практическая часть (14 заданий, кратко)

1. Установить Python, зафиксировать версию в отчёте.
2. Настроить VS Code + расширение + интерпретатор; директория `python_lab_02`.
3. `main.py` с `print("Hello, World!")`: запуск из IDE и из терминала — записать оба результата.
4. Переменные `name, age, height, is_student` → вывести, `type()`, изменить ≥2 и вывести снова.
5. Ввод имени/фамилии/возраста: показать тип возраста **до** преобразования, затем `int`, рост — `float`.
6. `a = 15, b = 4`: все семь операций; объяснить разницу `/` и `//`; изменить результат `2 + 3 * 4` скобками.
7. Калькулятор: два числа `float`, четыре действия, проверить на ≥2 наборах данных.
8. `for`+`range`: числа 1–10, затем 10–1, затем чётные 0–20, затем другой шаг.
9. Сумма чисел 1…n по вводимому пользователем `n`.
10. `while`: числа 10→1, затем «Цикл завершён»; объяснить условие выхода и зачем менять `count`.
11. `math`: длина окружности и площадь круга для `radius`, `math.sqrt`.
12. `if-elif-else`: положительное/отрицательное/ноль + чётность через `%`; показать на трёх входах (полож., отриц., ноль).
13. Доступ к лабе: `age >= 18 and has_access`; в отчёте — почему `and`, а не `or`.
14. **Самостоятельно:** ввести `n` измерений, в цикле собрать значения, вывести сумму и среднее (`n` — int, измерения — float, сумма накапливается).

## Требование к результату

Знать назначение интерпретатора и IDE; создавать и запускать программы; работать с `int/float/str/bool`, `input/print`, преобразованием типов и арифметикой; понимать `for`/`while`, `range()`, роль отступов, накопление результата; на базовом уровне — `import` и стандартную библиотеку.
