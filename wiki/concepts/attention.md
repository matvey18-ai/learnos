# Внимание (attention)

> Черновик подготовлен LLM (2026-10-02) по статье [[how-llms-actually-work-habr]]. Перепиши разделы Explanation и Example своими словами, сверь с разделами статьи и только после этого смени статус на `verified`.

## In one sentence

Механизм внимания — способ для каждого токена взвешенно подтянуть информацию из других доступных токенов: оценка «насколько похожи» превращается в веса, по которым усредняются их значения (Value).

## Explanation

Что это, как работает и почему важно. Факты — из статьи, моя интерпретация помечена отдельно.

Каждый токен в каждом слое преобразуется в три вектора: Query (что я ищу), Key (чем я обладаю), Value (что я передаю при совпадении). Скалярное произведение Query одного токена с Key другого даёт оценку сходства, softmax превращает набор оценок в веса с суммой 1, и новое представление токена — взвешенная сумма Value-векторов. Благодаря этому связь между словами находится даже на большом расстоянии предложения. В decoder-only моделях (GPT и т. п.) каузальная маска искусственно обнуляет веса будущих токенов: текст генерируется слева направо, и токен не может «заглядывать вперёд».

Один проход даёт лишь один способ связей, поэтому внимание запускают параллельно несколько раз — многоголовое внимание; у каждой головы свои обучаемые матрицы, проецирующие полный вектор токена в компактное подпространство. Стоимость внимания растёт квадратично с длиной последовательности, поэтому при генерации кэшируют уже вычисленные Key/Value (KV-кэш), а в GQA несколько Query-голов делят общие K/V-головы, уменьшая память.

_Моя интерпретация:_ внимание — это не «понимание» и не рассуждение, а перераспределение сигнала между позициями; все смысловые связи — побочный продукт обучения на предсказании следующего токена.

## Example

Из статьи [раздел «Механизм внимания»]: в предложении «The cat that I saw yesterday was sleeping» токен «was» ищет субъект действия: его Query лучше всего совпадает с Key слова «cat», у «yesterday» оценка низкая, поэтому после softmax «cat» получает большой вес в взвешенной сумме Value.

Самопроверка: почему два вектора, направленные «в одну сторону», дают большее скалярное произведение — и зачем его масштабировать до softmax?

## Boundaries and common mistakes

- Внимание не считает и не «понимает» смысл — оно пересчитывает веса; семантика связей выучена из частот.
- Головы не делят исходный вектор на фрагменты: каждая голова линейно проецирует весь вектор (частый миф, прямо опровергается в статье).
- Каузальная маска — ограничение архитектуры, а не случайность: будущее недоступно по построению.
- Квадратичный рост стоимости по длине контекста — поэтому длинный контекст дорог.
- Здесь не покрыто: строгое математическое выведение, индукционные головы (в статье только пересказ).
